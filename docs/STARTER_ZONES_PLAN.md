# Стартовые зоны: стопки ботов, простой, своя раса, «новичок рядом» — план

*19.10.2026 план, согласован с Глебом в тот же день (с правками, см. «Ответы»). Ветка `phase7`, PR #9 (драфт, не мёржить).*

## Проблема

В стартовых локациях (точно — школа Эйнхованта на TI, точки `-90875/248162`, `-90954/248118`, `-90918/248070`,
`-90890/248027`) боты стоят стопкой и ничего не делают. Две прошлые правки трогали только `Director` и не помогли.

Причины (проверено в коде):

1. `BotFactory`: новому боту ставится `template.getCreationPoint()`, затем `repo.ensureState(...)` и `r.setHome(...)`
   сохраняют эту точку как дом. У всех магов-людей это одни и те же 4 точки (у каждой расы/типа — свои).
2. `BotWorld.enter`: при `near == null && exact == null` бот входит в `p.getX/Y/Z()` из базы без разброса
   (создание, восстановление после рестарта) → столб.
3. `BotWorld.spotNear`: если 10 попыток `canMoveToTarget` не прошли — возвращается ровно центр → столб.
4. Простой: `BasicBrain.walk` проверяет каждый шаг и обход прямой линией `MobiusGeo.canMoveTo`
   (`canMoveToTarget`) независимо от `PathFinding`. Изнутри здания школы ни шаг, ни обход не проходят →
   через 6 неудач `returnToTown` → регион возврата школы = те же 4 точки → бесконечный цикл.
   `MobiusActuators.moveTo` при `PathFinding = 2` (сток, в Docker без оверрайда) ход не режет.
5. Smoke (`tools/smoke.sh`) работает тем же compose-проектом `l2s`, с теми же именами контейнеров, портами, сетью
   и образом `l2start-server:dev`, что и solo: при запуске заменяет контейнеры solo (отдельный только том БД).

## Простой (S3)

- Простой = бот хочет идти, но за 3 тика не сдвинулся > 50, **или** цели нет вообще.
- Намеренные состояния не простой, но у каждого свой максимум (превысил → простой):
  AFK — по таймеру AFK (≤ 10 мин), отдых — до порога HP/MP (≤ 3 мин), бой — пока цель жива и бьётся (≤ 2 мин без урона),
  transit у ГК — ≤ 15 с, группа в городе — по таймеру поручения (≤ 2 мин), торговля и бафер на посту — пока лавка/пост открыты.
- Реакция: сменить активность; повторный простой — телепорт к ближайшему подходящему споту, **только если бота не видит
  ни один живой игрок**, иначе бот бежит, телепорт ждёт.
- Стопка: ближе 50 к другому боту — разнести в любом состоянии; своя пати/группа — минимум 80–100.

## Стартовые зоны (S5, S6)

- Стартовая зона = полигон стартовой деревни (`world.xml`) + споты с `town=<стартовая деревня>` и `maxLevel ≤ 20`
  (`wasteland_5`, 25–27, помеченный `talking_island`, не входит).
- TI — люди, Elven Village — эльфы, Dark Elven Village — тёмные эльфы, Orc Village — орки, Dwarven Village — гномы.
  Вне стартовых зон расы смешанные, как сейчас.
- Гремлины (18342, `spawns/Others/Gremlins.xml`) есть у точек создания всех рас: TI (школа и порт), эльфы, тёмные эльфы,
  орки, гномы.

## Ключи bots-core

- `DirectorStarterTownMax` = 8 — городская активность в стартовой деревне (компаньоны и охотники не входят).
- `NewbieCompanions` = `1-2` (0 = выкл).

## Тесты

- 50 входов с одной сохранённой точки → все попарно ≥ 150, ни одного на центре.
- Миграция убирает стопки; восстановление после рестарта — разброс и своя раса в стартовой зоне.
- Бот 1 лвл на TI получает цель, не TOWN-idle; детектор простоя срабатывает (и не срабатывает на намеренных состояниях
  в их пределах); телепорт только без живого зрителя.
- Новый игрок любой расы → 1–2 компаньона его расы, бегут к ближайшим гремлинам, после 10–15 убийств уходят в деревню,
  повторно не появляются.
- В каждой стартовой зоне только своя раса.

## Ответы Глеба (19.10)

- Дамп — `//bots spots [radius]` (`//bots spawn` занят).
- Простой — исключая намеренные состояния; у каждого свой максимум или условие выхода.
- Граница стартовой зоны — полигон + споты `town=<стартовая>` с `maxLevel ≤ 20`.
- Лог входа: торговцы — одной сводной строкой, остальные — INFO на каждого.
- Бэкап-правки — отдельным коммитом; `DisableTutorial=False` осознанно.
- `DirectorStarterTownMax` по умолчанию 8 (4 было костылём против стопок).
- Телепорт при повторном простое — только без живого зрителя.
- Smoke — только после `backup-db.bat`, отдельным compose-проектом.

### Отличия от плана

- **Лавки торговцев и бафферы** (статус `TRADER`) входят в мир без разброса: их места раскладывает economy-market
  (решётка, отступы от NPC). Для всех остальных входов — разброс.
- **Миграция S2/S5** выполняется при каждом старте, а не один раз: она идемпотентна (повторно никого не двигает) и заодно
  чинит ботов, вышедших на стоковой точке после смерти.
- **Стартовая зона** = полигон деревни + её угодья ≤ 20 + **3000 вокруг стоковых точек создания** стартовых классов:
  точки создания эльфов, тёмных эльфов, орков, гномов и воинов-людей лежат далеко от деревень (эльфы ~8500) — без этого
  новичок у точки создания «не в стартовой зоне».
- Вход и возврат в город держат 150 и от стоковых точек создания/возврата (точки школы стоят в 50–90 друг от друга).
- Smoke сценарий 7: «на тех же местах» → «рядом, 150..2500» (вход всегда с разбросом).
- Причина простоя, найденная по ходу: `BasicBrain.walk` проверял каждый шаг прямой линией геодаты независимо от
  `PathFinding`; изнутри школы шаги не проходили → `returnToTown` → те же 4 точки школы → цикл.
