# Боты: PvP, ПК, кланы и академия

Простым языком — что делают боты в фазе 7 (solo). Технические ключи — в `modules/bots-core/MODULE.md` и `modules/bots-brain-basic/MODULE.md`.

## PvP

- Боты бьются с тобой в PvP-зонах по правилам стока (флаг, карма).
- **`PvpAggression`**: `off` — сами не нападают; `low` / `normal` / `high` — реже или чаще. Защита пати/клана и месть **не отключаются** `off`.
- **`PvpPlayerCooldown` (12 мин)**: один бот не кидает на тебя «первое» нападение чаще этого.
- Месть: если убил или сильно бил бота — он может ответить позже (не мгновенно).
- Дуэли: бот отвечает на вызов через хук (как игрок без клиента).

Админ: `//bots pvp` — счётчики часа; `//bots pk <имя>` — сделать ПК-бота рядом.

## ПК-боты

- Небольшая доля новых персон (`PkBotShare` ≈ 2 %).
- Экип ПК — **реальный** (ledger): при смерти падает по стоковой карме; тот же object id не появляется снова «из воздуха».

## Кланы ботов

- Часть пула в бот-кланах (`ClanBotShare=0.70`), два больших (lvl 8 × 40).
- Герб у каждого. В пати обычно соклановцы (иногда смешанная пати).
- **Не зовут в клан сами.** Если попросишь шёпотом лидера — может пригласить (`ClanInvitePlayers`).
- Ты можешь позвать бота в свой клан/академию — он отвечает по правилам (`ClanJoinPlayers`); торговцы и лидеры бот-кланов не уходят.

## Академия (набор)

- У ГК Глудина, Глудио, Диона, Гирана — рекрутёры с титулом «Набор в академию».
- Пишут в шаут/трейд в общих лимитах чата, например: «Клан NightHawk (8 лвл, КХ в Гиране, бафы) набирает…».
- **Инвайт только если ты попросишь** шёпотом («в академию», «возьмите в акаду», …). Сами не кидают.
- Условия: без клана, до 40, ещё не 2-я профа.
- Награда: **50 000** при вступлении, **150 000** при выпуске с 40 (один раз на персонажа; вышел раньше — второй выплаты нет).

## Кланхолы

- Клан с рекрутёром **сразу владеет** ближайшим свободным auctionable-холлом (иначе соседним); функции бафов / телепорта / регена на максимуме; склад клана пополняется, чтобы сток мог платить аренду (≥ 2 периода).
- Остальные бот-кланы участвуют в стоковом аукционе на долю `ClanHallBidShare`; ты можешь перебить.

Админ: `//bots clans`, `//bots clan <имя>` — КХ, рекрутёры, академисты, выплаты.
