## 0. Коротко

- **Цель этапа:** мир вокруг тебя умеет в PvP и в кланы «как живые». Боты нападают и защищаются там, где PvP разрешено; часть пула — ПК с настоящей кармой и настоящим дропом экипировки; 10–20 бот-кланов с гербами; тебя могут позвать в бот-клан, бот может вступить в твой; кланхолы покупаются на стоковом аукционе.
- **Профили:** **solo и online** (код один; в `online` при выключенных ботах механики инертны). `PvpAggression` по умолчанию **`normal`** в обоих профилях.
- **Не в этом этапе:** войны кланов, осады замков/фортов — **этап 8**.
- **Философия режиссёра не меняется.** PvP и клановая активность — только у ACTIVE (рядом с тобой) или у закреплённых (пати/клан с тобой). SIMULATED не дерётся.
- **x1 и ваниль:** дроп с ПК-бота — **полная стоковая** формула кармы (не только paperdoll). Исключение из «вещи бота исчезают»: у **ПК-ботов** предметы из ledger — реальные, падают по стоку, пополняются только через ledger (без дюпа).
- **`PvpAggression=off`:** гасит только **инициативу** (первое нападение на живого); защита пати/клана и месть остаются.
- **Шаги:** 7a основа PvP → 7b нападение/защита/дуэли → **КТ14** → 7c боты-ПК → 7d бот-кланы → 7e игрок и кланы → 7f кланхолы → 7g лимиты, админка, доки, PR → **КТ15**.
- **Объём:** ≈ 24–28 рабочих дней агента + 3–4 на правки по КТ. Размер **L**.
- **Модули:** логика PvP — `bots-brain-basic` (+ при необходимости тонкий `bots-pvp`); кланы — `bots-core` (стоковый `Clan` + таблицы модуля) или `bots-clans`. Предпочтительно не плодить модули без нужды: PvP в brain, кланы в core.
- **Ядро Mobius:** несколько маленьких хуков `[HOOK:P7-…]` (§1.2). Без модуля ботов — инертны / сток.

### 1.2 Сток Mobius и нужные хуки

| Механика | Что в стоке | Решение |
|---|---|---|
| Может ли A бить B | `Player.isAutoAttackable`, `checkPvpSkill`, зоны, флаг, карма, клан/пати | **Обычно без хука.** Если ПК-бот или encounter упирается в сток — тонкий **`[HOOK:P7-ATTACKABLE]`** (H12): модуль может разрешить/запретить атаку; без слушателя = сток. |
| Урон бот↔игрок | `reduceCurrentHp` + события урона | Сначала **без** transform-хука. **`[HOOK:P7-DAMAGE]`** (H13) — только если нужен clamp; иначе в бэклог. |
| Игрок зовёт бота в клан | `RequestJoinPledge`: нет клиента → «offline» / тишина | **`[HOOK:P7-BOT-PLEDGE]`**: guard `isBot` + `CoreHooks.botPledgeRequest` → мозг принимает/отклоняет стоковой последовательностью ответа. |
| Бот зовёт игрока в клан | Лидер-бот шлёт стоковый инвайт | **Без хука** (у игрока есть клиент). Решение — в мозге лидера (уровень, память). |
| Дуэль | `RequestDuelStart` к боту | **`[HOOK:P7-BOT-DUEL]`**: как pledge — бот принимает/отклоняет по характеру. |
| Альянс | `RequestJoinAlly` | **Не в 7** (или вежливый отказ тем же хуком pledge/ally, если всплывёт в смоуке). |
| Карма, дроп с ПК | Стоковый karma + item drop с игрока | ПК-бот — **настоящий** `Player` с реальными items → стоковый дроп. Ledger учитывает потерю и пополнение. |
| Кланхол / аукцион | `ClanHallAuction`, ставки, владение | **Без хука**, если бот-клан — обычный `Clan` с аденой на складе клана / у лидера по правилам модуля. |
| Академия | Стоковый academy pledge, выпуск с 40 | **Без хука**: бот 1–2 профы вступает в academy твоего клана и выпускается по стоку. |
| Клан-чат, репа, скиллы клана | Сток | **Без хука**: боты пишут в clan chat шаблонами; репа/скиллы — стоковые действия лидера/модуля. |

Итого ожидаемо **2–3 обязательных хука** (`P7-BOT-PLEDGE`, `P7-BOT-DUEL`, при необходимости `P7-ATTACKABLE`); `P7-DAMAGE` — опционально. Уже существующие `P7-DROP-FLOAT` / `P7-QUEST-REWARD` не трогаем.

## 5. Риски

- **Префикс `P7-`:** уже занят рейтами (`P7-DROP-FLOAT`). Новые ID должны быть уникальны (`P7-BOT-PLEDGE`, …).
- **Дюп экипа ПК:** только ledger + стоковый remove on death; тесты на «убил → зашёл снова → тот же меч не появился из воздуха».
- **Агрессия к игроку в solo:** слишком высокая — ломает кач; ручка `PvpAggression` + кулдаун обязательны до КТ14.
- **Кланхол-аукцион:** гонка ставок бот↔бот без лимита съест бюджет; нужен потолок и редкость переставок.
- **Осады/войны** нельзя «случайно» включить стоковым флагом клана — явный запрет до этапа 8.
- **Online без ботов:** хуки инертны; конфиги online не включают `PkBotShare` пока нет пула.

## 6. Решения Глеба (15.10.2026, ≈ 19:15 МСК)

1. **Префикс `P7-`:** ок (ID хуков этапа 7 отличаются от рейтов).
2. **`PvpAggression=off`:** гасит только **инициативу** (первое нападение на живого). Месть и защита пати/клана **работают**.
3. **Дефолт `PvpAggression`:** `normal` (средне) в **solo и online**.
