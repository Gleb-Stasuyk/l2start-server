# Диапазоны id для модулей

Модуль объявляет в `module.json` → `reserves` диапазоны id, которые он занимает. Платформа проверяет:
- все id в данных модуля лежат в его диапазонах (иначе INVALID);
- диапазоны разных включённых модулей не пересекаются (иначе REFUSED у второго по порядку);
- id не совпадает со стоковыми данными Mobius (иначе FAILED, данные модуля не грузятся).

Проверено по стоку Mobius CT_0 (9fb01cb205): в диапазоне **95000–99999** нет ни одного стокового NPC, мультиселла или байлиста
(NPC: до 35 656, плюс 21 кастомный 50007–1003000; мультиселлы и байлисты до девяти цифр, но не в этом диапазоне).
Поэтому модулям отдан диапазон 95000–99999. Даже при ошибке распределения сервер защищён проверкой совпадения со стоком.

| Модуль | NPC | Мультиселлы | Байлисты | Предметы | Скиллы |
|---|---|---|---|---|---|
| тестовые модули (`platform/test/fixtures`, только smoke) | 95000–95009 | 95000–95009 | 95010–95019 | — | — |
| свободно для модулей | 95100–99999 (блоками по 100) | 95100–99999 | 95100–99999 | позже | позже |
