# world-info

Списки телепортов у гейткиперов: к названию точки добавляется диапазон уровней монстров вокруг неё,
например «Cruma Tower (40-47)» (EXTRAS_PLAN §4, хук `P8-TELEPORT-NAME`, API 1.7).

- Диапазон = p10–p90 уровней обычных монстров (без рейдов), заспавненных в радиусе `Radius` (4000) от точки;
  меньше `MinSpawns` (5) спавнов или точка в городе — ничего не добавляется. Считается один раз на точку (кэш).
- Ручные значения: `data/teleport-levels.xml` (`<point x y levels="40-47"/>`, `levels=""` — скрыть).
- Выключить: `L2_MOD_WORLD_INFO__TELEPORTLEVELS=false` или `L2_MODULE_WORLD_INFO=off`.
