# return-skill

Каждый игрок (новые и старые персонажи, все классы) при входе получает скилл **95100 «Возвращение в город»**:
как Scroll of Escape (эффект `Escape TOWN`, те же условия, что у стокового 2013), но каст 60 с, без свитка,
откат 30 мин. Скилл выдаётся на каждом входе без записи в базу (проверка дерева скиллов его не трогает).

Данные: `data/skills` (тип данных модуля `skills`, API 1.12, хук `P9-DATA-SKILLS`).

Клиент: имя и иконку скилла клиент Interlude берёт из своих `skillname-e.dat` / `skillgrp.dat` по id. Без строки
для 95100 в клиенте скилл виден без иконки и названия; нужна строка с иконкой `icon.etc_scroll_of_escape_i00`.
